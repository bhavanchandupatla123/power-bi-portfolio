# Power BI Analytics Portfolio

A portfolio project demonstrating my Power BI workflow from data preparation and modelling through DAX, KPI design and business-facing visualisation.

## Featured project — Chocolate Insights Dashboard

The **Chocolate Insights** dashboard presents sales performance in a concise executive-style report. It was designed to make important commercial trends easy to understand without requiring users to inspect raw data.

### Dashboard highlights

- **£27.99M total sales**
- **2M total boxes**
- **78K total shipments**
- Sales trend analysis over time
- Product-level box sales
- Country-level sales contribution
- Salesperson performance ranking
- Interactive date filtering

### Business questions addressed

The dashboard helps answer questions such as:

- How are sales changing over time?
- Which products generate the highest volume?
- Which countries contribute most to revenue?
- Which salespeople are performing strongest?
- How do headline KPIs change when the reporting period changes?

## PL-300 practice model

I also developed a structured Power BI practice model using a multi-table sales dataset containing raw sales records and supporting dimensions. The model was used to practise the end-to-end skills required for analytics and PL-300 preparation, including cleaning messy source data, building relationships and creating reusable measures.

The practice data covers areas such as:

- Sales transactions
- Products
- Customers
- Dates
- Salespeople
- Regions
- Channels
- Order status and returns
