# Dataset & Modelling Notes

The PL-300 practice dataset is structured for end-to-end Power BI exercises covering data cleaning, modelling and DAX.

## Typical model structure

- **FactSales** — transactional sales data
- **DimProduct** — product attributes and categories
- **DimCustomer** — customer attributes
- **DimDate** — calendar table for time intelligence
- **Salesperson / Region dimensions** — supporting operational analysis

## Practice areas

The dataset is used to practise:

- Cleaning messy source data in Power Query
- Handling nulls, errors and inconsistent values
- Building a star schema
- Creating one-to-many relationships
- Managing active and inactive date relationships
- Building KPI measures
- Time intelligence
- Channel and category analysis
- Customer and regional analysis
- Returns and order-status reporting
- Validation of report totals

## Data handling

The workbook used for this practice is a portfolio/learning dataset. When publishing Power BI reports publicly, only non-confidential data should be used.
